# ScienceWork1
Цель проекта научить нейросеть предсказывать импульс электромагнитного поля, по требуемому воздействию на квантовую систему. Иными словами, мы подаем на вход нейросети какое мы желаем получить состояние системы, а на выходе получаем необходимую фазу, частоту и амплитуду сигнала, которым мы хотим воздействовать на систему.
В данном проекте реализована физическая симуляция уравнения Шредингера, которое описывает двухуровневую систему эволюционирующую под воздействием электромагнитного поля, изменяя ее состояние. Импульс электромагнитного поля изменяющий состояние квантовой системы называется Раби импульсом, и воздействует на нее как некий унитарный оператор действующий на вектор состояния системы.
В скрипте SchrodingerEquation.py происходит генерация случайных унитарных операторов, расчет и физическая симуляция Раби импульса. Создается массив данных: оператор (матрица вращающая вектор состояния системы по сфере Блоха) - параметры импульса (фаза, частота, амплитуда). На этом массиве мы обучаем нейросеть, обучение и проверка нейросети выполняются с помощью скрипта NeuralNetwork.
