# ScienceWork1
Предсказание параметров Раби-импульса с помощью нейронной сети

Описание проекта

Цель проекта — обучить нейронную сеть подбирать параметры электромагнитного импульса, необходимого для перевода квантовой системы из исходного состояния в заданное.

В качестве примера рассматривается двухуровневая квантовая система — система, имеющая два возможных базисных состояния. Её состояние можно представить в виде вектора на сфере Блоха, а изменение состояния под воздействием электромагнитного поля описать с помощью уравнения Шрёдингера.

Для управления состоянием системы используется Раби-импульс — электромагнитный импульс, воздействие которого изменяет квантовое состояние. В рассматриваемой модели его параметры включают фазу, частоту и амплитуду сигнала. Длительность импульса считается фиксированной.

Задача нейронной сети — решить обратную задачу управления: по заданному целевому состоянию определить параметры импульса, который с достаточной точностью переведёт систему в это состояние.
Реализация
Проект состоит из двух основных частей.

1. Физическое моделирование — SchrodingerEquation.py

Скрипт моделирует эволюцию двухуровневой квантовой системы под воздействием электромагнитного поля.

Для формирования обучающей выборки генерируются случайные целевые унитарные преобразования. Затем с помощью численного решения уравнения Шрёдингера моделируется воздействие импульсов с различными параметрами. В результате формируется набор данных, связывающий параметры импульса с соответствующим квантовым преобразованием.

Полученная выборка используется для обучения нейронной сети.

2. Обучение и тестирование — NeuralNetwork.py

Второй скрипт отвечает за обучение нейронной сети и проверку её предсказаний.

После запуска скрипта можно выбрать режим тестирования, введя 1. В этом режиме сети передаются тестовые целевые преобразования, для которых она предсказывает параметры Раби-импульса: фазу, частоту и амплитуду.

Затем предсказанные параметры используются для моделирования эволюции квантовой системы. Полученное состояние сравнивается с целевым, что позволяет оценить точность работы сети.
Результаты
На рисунке показан пример работы обученной нейронной сети. Красная стрелка обозначает целевое состояние системы, а зелёная — состояние, полученное после воздействия импульса с предсказанными сетью параметрами.

Почти полное совпадение стрелок показывает, что в данном примере нейросеть подобрала параметры импульса, обеспечивающие близкое к целевому конечное состояние квантовой системы.

Таким образом, проект демонстрирует возможность применения методов машинного обучения для решения обратной задачи управления двухуровневой квантовой системой.
